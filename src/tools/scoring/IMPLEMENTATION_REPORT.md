## 🚀 使用方法

### 1. 基本使用
1. 选择要评估的文本
2. 右键菜单选择 "AI智能评分系统"
3. 选择或创建评分卡
4. 查看评估结果

### 2. 快捷键
- **Ctrl+Alt+S**: 快速评估选中文本

### 3. 命令面板
- 打开命令面板 (Ctrl+Shift+P)
- 搜索 "AI智能评分系统"
- 选择相应功能
