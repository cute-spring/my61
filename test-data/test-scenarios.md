## 测试环境准备

### 系统要求

- AI智能评分系统已安装
- Copilot API 配置完成
- 网络连接正常

1. 从 `scoring-test-data.md` 中复制测试内容
2. 从 `sample-rubrics.md` 中导入评分标准
3. 准备测试文件用于评分
